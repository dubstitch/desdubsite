01 / Navigation

Constellation path

A visual navigation idea from this portfolio. Stars connect the steps instead of presenting another ordinary list.

See the animation code
path { stroke-dasharray: 340;
  animation: trace 4s ease-in-out infinite alternate; }
@keyframes trace {
  from { stroke-dashoffset: 340; }
  to { stroke-dashoffset: 0; }
}
@media (prefers-reduced-motion: reduce) {
  path { animation: none; }
}
