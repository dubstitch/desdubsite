# Future light rainbow theme

**Status: deferred.** This is a future visual design pass, not part of the current application-ready responsiveness and content work. Do not change the live color theme as part of today's fixes.

## Visual direction

- Maintain the light theme's clean white or near-white page backgrounds.
- Layer in a **very faint pastel rainbow hue** over the white. Use an ombré that subtly moves over time if it can be done without distraction, flashes or performance problems.
- Keep the overall effect delicate, airy and luminous, not saturated or muddy.
- Use **dark purple** for pill labels and other primary text so contrast remains readable.
- Apply **pastel rainbow gradient outlines** to pill buttons and selected interactive elements.
- Where glows belong, use a soft **rainbow gradient glow**, strategically applied. Avoid glowing every element.
- Preserve the existing portfolio's personality and polished typography while making the palette more visibly rainbow.
- Respect `prefers-reduced-motion`; make the static state equally attractive.
- Evaluate in both portrait and landscape, on small phones, tablets and desktop, before shipping.

## Sequence

1. Finish responsive layout, navigation, spacing and job-application-readiness work.
2. Apply to the two positions.
3. Return to the visual rainbow theme as its own deliberate design iteration.

This brief is intentionally saved for later, so the design details do not get lost.
